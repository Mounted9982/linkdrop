# LinkDrop 1.1

LinkDrop 是一个 Windows 桌面文件直传工具。它提供局域网共享文件夹、直接发送，以及不依赖公网 IP 的加密公网传输。

## 已实现

- 局域网设备自动发现
- 共享任意本地文件夹
- 对方按文件下载共享内容
- 文件夹打包为 ZIP 下载
- 直接发送多个文件或整个文件夹
- 文件夹层级在接收端保留
- TLS 加密传输
- 首次连接记录设备证书指纹，后续检测身份变化
- 接收方逐批确认，拒绝时可立即中止
- SHA-256 完整性校验，校验失败自动删除半成品
- 6 位配对码鉴权与失败限流
- 远程连接可达的 `IP:端口`
- 公网一次性口令：PAKE 端到端加密，P2P 优先、中继兜底
- 配置与接收目录持久化

## 本地运行

需要 Python 3.11+、Tkinter，并安装依赖：

```powershell
python -m pip install -r requirements.txt
python run.pyw
```

运行测试：

```powershell
python -m unittest discover -s tests -v
```

## Windows 打包

```powershell
.\build.ps1
```

生成的 `dist\LinkDrop.exe` 为单文件程序，已包含 croc 公网传输核心。首次启动时如果 Windows 防火墙弹出提示，请允许“专用网络”。

当前构建没有购买代码签名证书，因此从浏览器或聊天软件下载后，Windows SmartScreen 可能显示“未知发布者”。如果核对 SHA-256 与交付目录中的校验文件一致，可以手动允许运行。

## 局域网与远程

局域网内，两台电脑处于同一路由器或 Wi-Fi 下即可自动发现。不能发现时，手动输入另一台电脑概览页上显示的 `IP:端口`，再输入它显示的 6 位配对码。

局域网共享和输入地址直连需要接收端网络可达；远程可使用以下任一方式：

1. 接收端有可访问的公网 IPv4/IPv6，并已放行监听端口。
2. 路由器将接收端端口转发到该电脑。
3. 两台电脑已经通过 Tailscale、ZeroTier 等组网工具建立直连。此时填写组网工具分配的地址即可。
4. 不想配置端口转发时，进入“公网直连”页生成一次性口令，发送方和接收方使用 croc 的 PAKE 加密通道，自动尝试 P2P 或中继。

局域网共享和地址直连不经过云中转。公网一次性口令模式使用 croc 的公共中继作为连接协调和兜底；文件内容由两端协商的密钥端到端加密，中继不能直接读取明文。

公网模式默认使用 `1.getcroc.com:9009` 及其数据中继端口。它要求本机能够访问该服务；在公司网络、校园网或严格防火墙环境中，仍可能被拦截。

## 安全边界

- 配对码相当于访问凭据，不要发给不信任的人。
- 公网传输口令是单次凭据，每次传输都应重新生成。
- 只共享专门准备的文件目录，不要共享整个系统盘或用户目录。
- 收到文件后应自行确认来源；LinkDrop 不执行收到的文件。
- 局域网发现只广播设备名和端口，不广播配对码。
